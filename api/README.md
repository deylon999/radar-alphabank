# API

Контракт API «Радара» на TypeSpec: вход и сессии, пользователи и компании, заявки и участники,
профиль компании, лента выводов, вопросы по выводам, метрики качества и уведомления.
Общие правила (формат, ошибки, сессия, CSRF, размещение и CORS) описаны в `main.tsp`
и попадают в `info.description` OpenAPI. Внутренний API для Telegram-бота здесь пока не описан.

## Что где лежит

- `main.tsp` — точка входа: сервис и общие правила API;
- `common/` — общие вещи: ошибки в формате Problem Details, ответы, CSRF, cookie сессии;
- `auth/` — авторизация: `operations/` с эндпойнтами и `model/` с запросами, ответами и ошибками;
- `me/` — текущий пользователь, его членство в компании и должность;
- `companies/` — поиск, создание и профиль компании с данными банка;
- `join-requests/` — заявки на вступление в компанию;
- `members/` — участники компании, исключение, выход и передача прав владельца;
- `facts/` — описание и документы о компании, извлечение фактов и их проверка;
- `metrics/` — метрики качества выводов для команды и экспертов;
- `insights/` — лента выводов, сводка за неделю, обзор, карточка вывода, оценка и вопросы с потоком шагов агента;
- `notifications/` — настройки уведомлений и привязка Telegram.

## Сборка

```bash
npm install
sh compile.sh
```

Скрипт запускает `tsp compile` с `--warn-as-error`, так что любое предупреждение ломает сборку.

Готовая OpenAPI-спецификация (3.1.0) появится в `tsp-output/schema/openapi.yaml`.
